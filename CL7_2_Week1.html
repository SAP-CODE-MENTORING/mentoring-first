코드 속 ## 이 바뀌어요

시작 전에 이름 규칙과 Function Group 만들기

오늘 만드는 건 전부 로컬 오브젝트로 만들어요. 만들 때 Package를 묻는 창이 뜨면 Local Object 버튼을 누르면 돼요. 수업 패키지와 섞이지 않고, Transport Request 창도 안 떠요.

대상규칙예 (내 번호 기준)
프로그램YG##_MT주차_문제YG##_MT1_Q1
Function GroupYG##_MT (멘토링 전체에서 하나)YG##_MT
Function ModuleY_G##_MT_이름 (앞에 Y_ 필수)Y_G##_MT_SEAT_GET
DomainYG##_MT_D_이름YG##_MT_D_PCT
Data ElementYG##_MT_E_이름YG##_MT_E_PCT
StructureYG##_MT_S_이름YG##_MT_S_SEAT
Table TypeYG##_MT_TT_이름YG##_MT_TT_SEAT
길이 제한

프로그램·FM·Structure 이름은 30자, PARAMETERS·SELECT-OPTIONS 이름은 8자, DB 테이블은 16자까지예요. FM만 Y_G##…처럼 Y 뒤에 언더바가 붙는 건, 고객 FM 이름이 Y_나 Z_로 시작해야 하는 규칙 때문이에요.

Function Group은 오늘 처음 한 번만 만들어요. SE37 → 메뉴 Goto → Function Groups → Create Group → 이름 YG##_MT, 설명 “멘토링” → Local Object. 만든 다음 SE80에서 그룹을 활성화해 두세요.

원본 HW-2C · 비행일정별 좌석 조회

아래 문제들은 HW-2C에서 출발해요. 모범 답안은 강사님 리뷰 코드예요. 내 코드와 조금 달라도 흐름이 같으면 괜찮아요. 시작 전에 내 HW-2C를 한 번 실행해 보고 오세요.

만든 것
Program
ZHWG##_2C (강사님 리뷰 코드는 ZHWG00_2C_REVIEW)
입력
PA_CAR (항공사), SO_CON (노선), SO_FLD (비행일자) · SELECT-OPTIONS는 SDYN_BOOK로 만든 GS_BOOK의 칸을 FOR에 씀
결과
SFLIGHT 9칸 + 계산 6칸 = 15칸. 종류별로 묶음 (최대 → 예약 → 잔여 → 예약률, 각각 Economy·Business·First)
정렬
잔여좌석 많은 순 (Economy → Business → First)
짚고 갈 것 세 가지

① SELECT 칸 순서와 Structure 앞 9칸의 순서가 같아서 INTO TABLE로 바로 받을 수 있어요. 순서가 다르면 INTO CORRESPONDING FIELDS OF TABLE이 필요해요(복습 5). ② 계산은 LOOP 안에서 하고 MODIFY로 테이블에 다시 넣어요. ③ DESCENDING은 바로 앞 칸에만 붙어서, 칸마다 따로 적어야 해요.

TYPES TY_RATE TYPE P LENGTH 3 DECIMALS 2.

TYPES: BEGIN OF TS_FLIGHT,

         SEATSFREE_F TYPE SFLIGHT-SEATSOCC_F, " 잔여 좌석수 (First)

DATA GS_FLIGHT LIKE LINE OF GT_FLIGHT.

INITIALIZATION.

  SET TITLEBAR 'TITLE'.

  " -----------------------------------------------------------------------

START-OF-SELECTION.
  " -----------------------------------------------------------------------

  " [HW-2C] 비행일정별 좌석 조회 G##
  SET TITLEBAR 'TITLE'.

  " 3. SFLIGHT 조회 (Array Fetch)
  SELECT CARRID CONNID FLDATE SEATSMAX SEATSMAX_B SEATSMAX_F SEATSOCC SEATSOCC_B SEATSOCC_F
    FROM SFLIGHT
    INTO TABLE GT_FLIGHT
    WHERE CARRID  = PA_CAR
      AND CONNID IN SO_CON
  AND FLDATE IN SO_FLD.

  " 4. 조회 실패 시 오류 메시지 출력 후 중단
  IF SY-SUBRC <> 0.
    WRITE / '조회 조건에 해당하는 비행일정 데이터가 없습니다.'
          COLOR COL_NEGATIVE.
    RETURN.
  ENDIF.

  " 5. 잔여 좌석수 / 예약률 계산
  LOOP AT GT_FLIGHT INTO GS_FLIGHT.

    " 잔여 좌석수
    GS_FLIGHT-SEATSFREE   = GS_FLIGHT-SEATSMAX   - GS_FLIGHT-SEATSOCC.
    GS_FLIGHT-SEATSFREE_B = GS_FLIGHT-SEATSMAX_B - GS_FLIGHT-SEATSOCC_B.
    GS_FLIGHT-SEATSFREE_F = GS_FLIGHT-SEATSMAX_F - GS_FLIGHT-SEATSOCC_F.

    " Economy 예약율 계산
    PERFORM CALCULATE_RATE: USING    GS_FLIGHT-SEATSOCC
                                     GS_FLIGHT-SEATSMAX
                            CHANGING GS_FLIGHT-RATE,         " 콤마

                            " Business 예약율 계산
                            USING    GS_FLIGHT-SEATSOCC_B
                                     GS_FLIGHT-SEATSMAX_B
                            CHANGING GS_FLIGHT-RATE_B,       " 콤마

                            " First 예약율 계산
                            USING    GS_FLIGHT-SEATSOCC_F
                                     GS_FLIGHT-SEATSMAX_F
                            CHANGING GS_FLIGHT-RATE_F.

    MODIFY GT_FLIGHT FROM GS_FLIGHT.

  ENDLOOP.

  " 잔여 좌석수 기준 내림차순 정렬 (Economy → Business → First)
  SORT GT_FLIGHT BY SEATSFREE   DESCENDING
                    SEATSFREE_B DESCENDING
                    SEATSFREE_F DESCENDING.

  " 6. 화면 출력
  " - 헤더
  WRITE: /(10) TEXT-F01 CENTERED,        " 항공사ID
          (10) TEXT-F02 CENTERED,        " 항공편NO
          (14) TEXT-F03 CENTERED,        " 비행일자
          (10) TEXT-F04 RIGHT-JUSTIFIED, " Eco 최대
          (10) TEXT-F05 RIGHT-JUSTIFIED, " Eco 예약
          (10) TEXT-F06 RIGHT-JUSTIFIED, " Eco 잔여
          (10) TEXT-F07 RIGHT-JUSTIFIED, " Eco %
          (10) TEXT-F08 RIGHT-JUSTIFIED, " Biz 최대
          (10) TEXT-F09 RIGHT-JUSTIFIED, " Biz 예약
          (10) TEXT-F10 RIGHT-JUSTIFIED, " Biz 잔여
          (10) TEXT-F11 RIGHT-JUSTIFIED, " Biz %
          (10) TEXT-F12 RIGHT-JUSTIFIED, " 1st 최대
          (10) TEXT-F13 RIGHT-JUSTIFIED, " 1st 예약
          (10) TEXT-F14 RIGHT-JUSTIFIED, " 1st 잔여
          (10) TEXT-F15 RIGHT-JUSTIFIED. " 1st %
  ULINE.

  " - 데이터 (Key: Color + 가운데 정렬 / 숫자: No sign + 우측 정렬)
  LOOP AT GT_FLIGHT INTO GS_FLIGHT.
    WRITE: /(10) GS_FLIGHT-CARRID      COLOR COL_KEY CENTERED,
            (10) GS_FLIGHT-CONNID      COLOR COL_KEY CENTERED,
            (14) GS_FLIGHT-FLDATE      COLOR COL_KEY CENTERED,
            (10) GS_FLIGHT-SEATSMAX    NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-SEATSOCC    NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-SEATSFREE   NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-RATE        NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-SEATSMAX_B  NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-SEATSOCC_B  NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-SEATSFREE_B NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-RATE_B      NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-SEATSMAX_F  NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-SEATSOCC_F  NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-SEATSFREE_F NO-SIGN RIGHT-JUSTIFIED,
            (10) GS_FLIGHT-RATE_F      NO-SIGN RIGHT-JUSTIFIED.
  ENDLOOP.

  " ---------------------------------------------------------------------
  " START-OF-SELECT 끝.
  " ---------------------------------------------------------------------

*&---------------------------------------------------------------------*
*& Form CALCULATE_RATE
*&---------------------------------------------------------------------*
FORM CALCULATE_RATE USING    VALUE(PV_SEATSOCC) TYPE SFLIGHT-SEATSOCC
                             VALUE(PV_SEATSMAX) TYPE SFLIGHT-SEATSMAX
                    CHANGING CV_RATE            TYPE TY_RATE.

  " 예약률(%) - 최대 좌석수가 0인 경우 0으로 처리 (Zero Divide 방지)

  IF PV_SEATSMAX = 0.

    CV_RATE = 0.

  ELSE.

    CV_RATE = 100 * PV_SEATSOCC / PV_SEATSMAX.

  ENDIF.
ENDFORM.

짚고 갈 것 예약률 계산이 클래스마다 세 번 반복돼서 FORM CALCULATE_RATE 하나로 묶었어요. USING으로 예약·최대 좌석을 넘기고 CHANGING으로 예약률을 돌려받아요. First 클래스가 없는 항공편은 최대 좌석이 0이라서, 0으로 나누기 덤프도 FORM 안에서 한 번에 막아요.

복습 2 예약률이 기준 이상인 일정만 ★★☆

목적조건에 맞는 것만 골라 담기 (필터링)
연습LOOP 안 IF + APPEND로 새 테이블에 담기 · READ TABLE … INDEX 1로 비었는지 확인 · “일정 없음”과 “기준 넘는 일정 없음” 구분
요청서운항관리팀 · 증편 검토용
이코노미 예약률이 기준 이상인 일정만 보고 싶어요. 기준은 상황마다 달라서 몇 % 이상인지는 제가 직접 넣을게요. 기준을 넘는 일정이 하나도 없으면, 일정 자체가 없는 거랑 구분해서 알려 주세요.
만들 것
Program
YG##_MT1_Q2 (복습 1을 복사해서 시작)
입력
복습 1 + PA_PCT (기준 예약률, TYPE I)
변수
GT_ECO (읽은 전체), GT_RESULT (기준 이상만, 같은 TT_ECO 타입)
메시지

힌트

힌트 1

계산하는 LOOP 안에서, 예약률을 구한 바로 다음에 IF를 하나 두세요. 기준 이상이면 APPEND GS_ECO TO GT_RESULT.로 다른 테이블에 담아요.

힌트 2

테이블에서 줄을 지우는 문법은 아직 안 배웠어요. 그래서 “기준 미만을 지우기” 대신 “기준 이상만 새 테이블에 담기”로 풀어요. 출력도 GT_RESULT로 해요.

FUNCTION Y_G##_MT_SEAT_GET.

  DATA LS_SEAT LIKE LINE OF ET_SEATS.

  " 1. 입력값 점검: 잘못된 기간이면 읽지 않고 바로 끝
  IF IV_DATE_FROM > IV_DATE_TO.
    RAISE WRONG_PERIOD.
  ENDIF.

  " 2. 조회: SELECT-OPTIONS 대신 값 하나씩 받아서 EQ / GE / LE
  SELECT
      CARRID
      CONNID
      FLDATE
      SEATSMAX
      SEATSOCC
      SEATSMAX_B
      SEATSOCC_B
      SEATSMAX_F
      SEATSOCC_F
  FROM SFLIGHT
  INTO CORRESPONDING FIELDS OF TABLE ET_SEATS
  WHERE CARRID EQ IV_CARRID
    AND CONNID EQ IV_CONNID
    AND FLDATE GE IV_DATE_FROM
    AND FLDATE LE IV_DATE_TO.

  IF SY-SUBRC NE 0.
    RAISE NO_DATA.
  ENDIF.

  " 3. 계산: HW-2C의 4번 그대로

    LS_SEAT-SEATSFREE   = LS_SEAT-SEATSMAX   - LS_SEAT-SEATSOCC.

    LS_SEAT-SEATSFREE_F = LS_SEAT-SEATSMAX_F - LS_SEAT-SEATSOCC_F.

    IF LS_SEAT-SEATSMAX > 0.
      LS_SEAT-RATE = 100 * LS_SEAT-SEATSOCC / LS_SEAT-SEATSMAX.
    ENDIF.
    IF LS_SEAT-SEATSMAX_B > 0.
      LS_SEAT-RATE_B = 100 * LS_SEAT-SEATSOCC_B / LS_SEAT-SEATSMAX_B.
    ENDIF.
    IF LS_SEAT-SEATSMAX_F > 0.
      LS_SEAT-RATE_F = 100 * LS_SEAT-SEATSOCC_F / LS_SEAT-SEATSMAX_F.
    ENDIF.

    MODIFY ET_SEATS FROM LS_SEAT.
  ENDLOOP.

  " 4. 노선이 하나라서 날짜 순으로
  SORT ET_SEATS BY FLDATE.

ENDFUNCTION.

예시 실무처럼 정리하면

문제는 아니고, 오늘 만든 Dictionary 타입과 FM을 실무 프로그램처럼 쓰면 어떤 모양이 되는지 보여 주는 예시예요. FM으로 한 번 읽고, 같은 출력 코드를 클래스만 바꿔서 세 번 써요.

아직 같이 다루지 않은 OBLIGATORY(필수 입력)도 들어 있어요. 실제 코드가 어떻게 생겼는지 미리 보는 거라 지금 다 이해하지 않아도 괜찮아요.

구성
Program
YG##_MT1_EX
입력
PA_CAR, PA_CON, PA_FROM, PA_TO (모두 필수 입력)
조회
복습 3의 Y_G##_MT_SEAT_GET
출력
SHOW_CLASS 하나로 Economy · Business · First 세 블록
FM과 Dictionary 타입을 쓰는 프로그램
REPORT YG##_MT1_EX.

*----------------------------------------------------------------------*
* 선택 화면
*----------------------------------------------------------------------*
PARAMETERS: PA_CAR  TYPE S_CARR_ID OBLIGATORY,
            PA_CON  TYPE S_CONN_ID OBLIGATORY,
            PA_FROM TYPE S_DATE    OBLIGATORY,
            PA_TO   TYPE S_DATE    OBLIGATORY.

DATA GT_SEATS TYPE YG##_MT_TT_SEAT.

*----------------------------------------------------------------------*
* 메인: FM으로 읽고, 클래스별로 세 블록 출력
*----------------------------------------------------------------------*
START-OF-SELECTION.

  CALL FUNCTION 'Y_G##_MT_SEAT_GET'
    EXPORTING
      IV_CARRID    = PA_CAR
      IV_CONNID    = PA_CON
      IV_DATE_FROM = PA_FROM
      IV_DATE_TO   = PA_TO
    IMPORTING
      ET_SEATS     = GT_SEATS
    EXCEPTIONS
      NO_DATA      = 1
      WRONG_PERIOD = 2
      OTHERS       = 3.

  CASE SY-SUBRC.
    WHEN 0.
      PERFORM SHOW_CLASS USING 'E' 'Economy'.
      PERFORM SHOW_CLASS USING 'B' 'Business'.
      PERFORM SHOW_CLASS USING 'F' 'First'.
    WHEN 1.
      WRITE / '조회된 일정이 없습니다.'.
    WHEN 2.
      WRITE / '시작일이 종료일보다 늦습니다.' COLOR COL_NEGATIVE.
    WHEN OTHERS.
      WRITE / '알 수 없는 오류가 발생했습니다.'.
  ENDCASE.

*----------------------------------------------------------------------*
* 공통: 클래스 하나 출력 (E/B/F 중 어떤 칸을 쓸지 USING으로 받음)
*----------------------------------------------------------------------*
FORM SHOW_CLASS USING PV_CLASS TYPE C
                      PV_TITLE TYPE CSEQUENCE.

  DATA: LS_SEAT TYPE YG##_MT_S_SEAT,
        LV_MAX  TYPE S_SEATSMAX,
        LV_OCC  TYPE S_SEATSOCC,
        LV_FREE TYPE S_SEATSMAX,
        LV_PCT  TYPE YG##_MT_E_PCT.

  SKIP.
  WRITE / PV_TITLE COLOR COL_HEADING.
  ULINE.

  LOOP AT GT_SEATS INTO LS_SEAT.
    CASE PV_CLASS.
      WHEN 'E'.
        LV_MAX  = LS_SEAT-SEATSMAX.
        LV_OCC  = LS_SEAT-SEATSOCC.
        LV_FREE = LS_SEAT-SEATSFREE.
        LV_PCT  = LS_SEAT-RATE.
      WHEN 'B'.
        LV_MAX  = LS_SEAT-SEATSMAX_B.
        LV_OCC  = LS_SEAT-SEATSOCC_B.
        LV_FREE = LS_SEAT-SEATSFREE_B.
        LV_PCT  = LS_SEAT-RATE_B.
      WHEN 'F'.
        LV_MAX  = LS_SEAT-SEATSMAX_F.
        LV_OCC  = LS_SEAT-SEATSOCC_F.
        LV_FREE = LS_SEAT-SEATSFREE_F.
        LV_PCT  = LS_SEAT-RATE_F.
    ENDCASE.

    WRITE: /(14) LS_SEAT-FLDATE COLOR COL_KEY CENTERED,
            (10) LV_MAX  NO-SIGN RIGHT-JUSTIFIED,
            (10) LV_OCC  NO-SIGN RIGHT-JUSTIFIED,
            (10) LV_FREE NO-SIGN RIGHT-JUSTIFIED,
            (10) LV_PCT  NO-SIGN RIGHT-JUSTIFIED.
  ENDLOOP.

ENDFORM.

코드에서 볼 것

  • 원본의 CALCULATE_RATE처럼 서브루틴(FORM … ENDFORM)으로 묶었어요. 코드 묶음에 이름을 붙여 두고 PERFORM 이름으로 불러요. 이 프로그램 안에서만 쓰는 작은 FM이라고 보면 돼요.
  • 같은 코드는 한 번만 써요. 세 클래스의 출력 모양이 같아서 SHOW_CLASS 하나로 만들고, 어떤 클래스인지('E', 'B', 'F')만 USING으로 넘겨요. 안에서는 수업에서 쓴 CASE로 칸을 골라요.
  • Dictionary 타입은 어디서든 같은 이름으로 써요. FM의 ET_SEATS, 프로그램의 GT_SEATS, FORM 안의 LS_SEAT·LV_PCT가 모두 복습 3에서 만든 YG##_MT_… 타입이에요. 칸을 하나 바꾸고 싶으면 SE11에서 한 번만 고치면 돼요.
  • 변수 이름 앞글자로 어디서 쓰는 변수인지 알 수 있어요. PA_ 선택 화면, GT_·GS_ 프로그램 전체, LS_·LV_ FORM 안 지역 변수, PV_ FORM이 받는 값.

참고 ALV로 보여 주기 (2주차 미리보기)

이번 주에는 하지 않아요. 이번 주 수업에서 배운 Screen·Container·ALV를 오늘 만든 FM과 Structure에 붙이면 어떻게 되는지, 시간 날 때 참고로 보세요. 다음 주 멘토링에서 이어서 직접 만들어 봐요.

구조는 수업의 Exercise 26(SAPMZBC400_G##_EX26_D)과 같아요. 다른 점은 두 가지예요. FM은 복습 3의 Y_G##_MT_SEAT_GET을 쓰고, ALV의 I_STRUCTURE_NAME에는 복습 3에서 만든 YG##_MT_S_SEAT를 넘겨요.

  1. 준비 1Module Pool SAPMYG##_MT1 (TOP Include MYG##_MT1TOP와 함께, Local Object)
  2. 준비 2Screen 100: 입력 필드 4개(Layout의 Dictionary/Program Fields에서 GV_CARRID, GV_CONNID, GV_FROM, GV_TO 가져오기, 항공사·노선은 필수 입력), 버튼 “조회”(Function Code GO), Element List 맨 아래 OK 필드 OK_CODE
  3. 준비 3Screen 200: Custom Control CC_ALV를 화면 가득 그리기, OK 필드 OK_CODE
  4. 준비 4GUI Status S100, S200: Function Key에 BACK(F3), EXIT(Shift+F3)
  5. 준비 5Transaction Code YG##_MT1 (시작 화면 100)로 실행

INCLUDE MYG##_MT1TOP.  " Global Data

MYG##_MT1TOP · 전역 변수
PROGRAM SAPMYG##_MT1.

" 화면변수 OK_CODE와 이름이 같아서, 누른 버튼의 Function Code를 받는다.
DATA OK_CODE TYPE SY-UCOMM.

" OK_CODE를 옮겨 담아 두는 변수 (OK_CODE는 바로 지우기 위해)
DATA GV_SAVE_OK TYPE SY-UCOMM.

" 100번 화면 입력 필드와 이름이 같아서, 입력한 값을 자동으로 받는다.
DATA: GV_CARRID TYPE S_CARR_ID,
      GV_CONNID TYPE S_CONN_ID,
      GV_FROM   TYPE S_DATE,
      GV_TO     TYPE S_DATE.

" FM 결과 = 200번 화면 ALV에 출력할 데이터 (복습 3에서 만든 Table Type)
DATA GT_SEATS TYPE YG##_MT_TT_SEAT.

" 화면에 ALV를 출력하기 위한 참조변수 2개
DATA GO_CONTAINER TYPE REF TO CL_GUI_CUSTOM_CONTAINER.
DATA GO_ALV_GRID  TYPE REF TO CL_GUI_ALV_GRID.
Screen 100 / 200 · Flow Logic
" ---- 100번 화면 Flow Logic ----
PROCESS BEFORE OUTPUT.
  MODULE STATUS_0100.

PROCESS AFTER INPUT.
  MODULE USER_COMMAND_0100.

" ---- 200번 화면 Flow Logic ----
PROCESS BEFORE OUTPUT.
  MODULE STATUS_0200.
  MODULE INIT_CONTROL_PROCESSING_0200.

PROCESS AFTER INPUT.
  MODULE USER_COMMAND_0200.
MYG##_MT1O01 · PBO
MODULE STATUS_0100 OUTPUT.
  SET PF-STATUS 'S100'.
ENDMODULE.

MODULE STATUS_0200 OUTPUT.
  SET PF-STATUS 'S200'.
ENDMODULE.

MODULE INIT_CONTROL_PROCESSING_0200 OUTPUT.

  " 처음 한 번만 객체를 만들고, 다음부터는 새로고침만 한다.
  IF GO_CONTAINER IS INITIAL.

    CREATE OBJECT GO_CONTAINER
      EXPORTING
        CONTAINER_NAME = 'CC_ALV'  " 200번 화면에서 만든 Custom Control 이름
      EXCEPTIONS
        OTHERS         = 1.

    CREATE OBJECT GO_ALV_GRID
      EXPORTING
        I_PARENT = GO_CONTAINER
      EXCEPTIONS
        OTHERS   = 1.

    " 칸 정보는 Dictionary Structure 이름만 넘기면 자동으로 잡힌다.
    CALL METHOD GO_ALV_GRID->SET_TABLE_FOR_FIRST_DISPLAY
      EXPORTING
        I_STRUCTURE_NAME = 'YG##_MT_S_SEAT'
      CHANGING
        IT_OUTTAB        = GT_SEATS
      EXCEPTIONS
        OTHERS           = 1.

  ELSE.
    CALL METHOD GO_ALV_GRID->REFRESH_TABLE_DISPLAY.
  ENDIF.

ENDMODULE.
MYG##_MT1I01 · Screen 100 PAI
MODULE USER_COMMAND_0100 INPUT.

  " OK_CODE는 옮겨 담고 바로 지운다.
  " 안 지우면 200번에서 돌아온 뒤 엔터만 쳐도 'GO'가 다시 실행될 수 있다.
  GV_SAVE_OK = OK_CODE.
  CLEAR OK_CODE.

  CASE GV_SAVE_OK.
    WHEN 'GO'.
      CALL FUNCTION 'Y_G##_MT_SEAT_GET'
        EXPORTING
          IV_CARRID    = GV_CARRID
          IV_CONNID    = GV_CONNID
          IV_DATE_FROM = GV_FROM
          IV_DATE_TO   = GV_TO
        IMPORTING
          ET_SEATS     = GT_SEATS
        EXCEPTIONS
          NO_DATA      = 1
          WRONG_PERIOD = 2
          OTHERS       = 3.

      CASE SY-SUBRC.
        WHEN 0.
          CALL SCREEN 0200.
        WHEN 1.
          MESSAGE '조회된 일정이 없습니다.' TYPE 'I'.
        WHEN 2.
          MESSAGE '시작일이 종료일보다 늦습니다.' TYPE 'I'.
        WHEN OTHERS.
          MESSAGE '알 수 없는 오류가 발생했습니다.' TYPE 'I'.
      ENDCASE.

    WHEN 'BACK' OR 'EXIT'.
      LEAVE PROGRAM.
  ENDCASE.

ENDMODULE.
MYG##_MT1I02 · Screen 200 PAI
MODULE USER_COMMAND_0200 INPUT.

  GV_SAVE_OK = OK_CODE.
  CLEAR OK_CODE.

  CASE GV_SAVE_OK.
    WHEN 'BACK' OR 'EXIT'.
      " 200번을 부른 곳(100번 PAI의 CALL SCREEN 다음 줄)으로 돌아간다.
      SET SCREEN 0.
  ENDCASE.

ENDMODULE.

코드에서 볼 것

  • Screen Processing 순서대로 읽어 보세요. 100번 PBO(STATUS_0100) → 화면 표시 → 조회 버튼 → 화면 값이 이름이 같은 GV_ 변수와 OK_CODE로 넘어옴 → PAI(USER_COMMAND_0100) → CALL SCREEN 0200 → 200번 PBO에서 ALV 생성.
  • OK_CODE는 옮겨 담고 바로 지워요. 안 지우면 200번에서 돌아온 뒤 엔터만 쳐도 이전 값(GO)이 다시 실행될 수 있어요. 실무에서 거의 항상 이렇게 써요.
  • 객체는 한 번만 만들어요. IF GO_CONTAINER IS INITIAL로 처음에만 Container와 ALV를 만들고, 다시 조회했을 때는 REFRESH_TABLE_DISPLAY로 새 데이터만 다시 읽어요. 수업 코드와 같은 흐름이에요.
  • Dictionary에 만들어 둔 덕을 여기서 봐요. I_STRUCTURE_NAME = 'YG##_MT_S_SEAT' 한 줄로 15칸이 자동으로 잡히고, 예약률 칸 머리글에는 복습 3에서 Data Element에 넣은 Field Label “예약률”이 나와요. 반대로 잔여좌석 칸은 예약 좌석의 Data Element를 빌려 써서 머리글도 “예약…”으로 나와요. 잔여좌석용 Data Element를 따로 만들면 고칠 수 있어요.
  • SET SCREEN 0은 200번을 부른 곳, 즉 100번 PAI의 CALL SCREEN 0200 다음 줄로 돌아가요. 그래서 다시 100번 화면이 보여요.
